# 🤖 AI セットアップ

AI（クロード）を使えるようにする手順だよ！

## やること（最初の1回だけ）

### 1. ターミナルを開く

### 2. 下のコマンドをコピペして Enter

```bash
source scripts/lit-webs-ai.sh
```

案内にしたがって進めてね！

## 2回目以降は何もしなくてOK ✨

最初のログインが成功すると、`~/.bashrc`（zsh の人は `~/.zshrc`）に「自動で読み込む設定」が
1 行だけ登録されるよ。だから次からは **ターミナルを開くだけ** で AI に繋がる状態になる。
毎回 `source` し直す必要はないよ。

- 仕組み: シェルが起動するたびに `WEBS_AI_REFRESH=1 source <このスクリプト>` を無人で実行し、
  保存済みのアクセスキー・モデル（フル ID）・接続先 URL を読み込む。
- アクセスキーは失効しない限り期限切れにならないので、再ログインは基本不要。
- 別アカウントに切り替えたい / ログアウトしたいときは `webs-logout` を実行してね。

## 起動できているか確認したいとき

`claude` の起動画面のモデル名が **Sonnet 4.6**（=フル ID `global.anthropic.claude-sonnet-4-6`）に
なっていれば OK。`Opus 4.8` や `Not logged in` と出る場合は読み込みができていないので、
もう一度 `source scripts/lit-webs-ai.sh` を実行してね。
