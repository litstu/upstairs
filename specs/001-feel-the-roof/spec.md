# Feature Specification: FeelTheRoof

**Feature Branch**: `001-feel-the-roof`

**Created**: 2026-08-07

**Status**: Draft

## User Scenarios & Testing

### User Story 1 - タスク登録と集中タイマーの開始 (Priority: P1)

ユーザーがアカウントを作ってログインし、タスクを登録して集中タイマーをスタートする。タイマー中はBongoCat風のキャラクターが画面に表示されて一緒に頑張ってくれる。タイマーが終わったら達成記録が保存される。

**初めて来た人の体験**:
トップページに来ると「FeelTheRoof」というタイトルとログイン/新規登録ボタンが見える。新規登録でアカウント名「しき」とパスワードを入力して登録。ログイン後のマイページには「今日のタスク」欄があり、「数学の課題」という名前・締め切り「2026-08-10」でタスクを登録する。タスク一覧に表示された「数学の課題」の横にある「集中開始」ボタンを押すと集中タイマー画面へ。中央にBongoCat風のキャラクターが表示され、25分タイマーがカウントダウンされる。タイマー完了後、達成ポップアップが出てカレンダーにその日の達成が記録される。

**Why this priority**: サービスの核心。これなしには成立しない。

**Independent Test**: タスクを1件登録 → タイマー開始 → タイマー完了 → カレンダーに記録されていることを確認、で完全にテスト可能。

**Acceptance Scenarios**:

1. **Given** 未ログイン状態, **When** トップページにアクセスする, **Then** ログイン/新規登録ボタンが見える
2. **Given** 新規登録画面, **When** アカウント名とパスワードを入力して送信する, **Then** アカウントが作成されてマイページに遷移する
3. **Given** ログイン済みのマイページ, **When** タスク名・締め切り日を入力して登録する, **Then** タスク一覧に表示される
4. **Given** タスク一覧, **When** 「集中開始」ボタンを押す, **Then** 集中タイマー画面に遷移してカウントダウンが始まる
5. **Given** 集中タイマー画面, **When** タイマーが0になる, **Then** 達成ポップアップが表示され、カレンダーに記録される

---

### User Story 2 - タスクの締め切り設定とカレンダー確認 (Priority: P2)

登録したタスクに締め切り日を設定し、カレンダー画面でどの日に何を達成したかを振り返れる。

**Why this priority**: 習慣化の実感に欠かせない。達成履歴が見えると継続モチベが上がる。

**Independent Test**: タスクに締め切りを設定 → タイマー完了 → カレンダー画面で当日に達成マークが付いていることを確認。

**Acceptance Scenarios**:

1. **Given** タスク登録画面, **When** 締め切り日を設定して登録する, **Then** タスク一覧に締め切り日が表示される
2. **Given** カレンダー画面, **When** 集中タイマーを完了した日を確認する, **Then** その日に達成マークが表示される
3. **Given** カレンダー画面, **When** 達成マークのついた日をタップする, **Then** その日に完了したタスク名が表示される

---

### User Story 3 - AIによるスモールステップ分解と励まし (Priority: P3)

大きなタスクをAIに分解してもらい、小さなステップとそれぞれの目安期限を提案してもらえる。また集中後にAIから励ましのメッセージをもらえる。

**Why this priority**: 取り掛かりやすさを高める差別化機能。コアが動いてから追加する。

**Independent Test**: タスクを1件登録 → AI分解ボタンを押す → スモールステップ案が表示される、で独立してテスト可能。

**Acceptance Scenarios**:

1. **Given** タスク詳細画面, **When** 「AIに分解してもらう」ボタンを押す, **Then** AIがタスクをスモールステップに分解した提案（ステップ名・目安期限）が表示される
2. **Given** AI提案画面, **When** 提案されたステップを採用する, **Then** 各ステップがサブタスクとして登録される
3. **Given** 集中タイマー完了後, **When** 達成ポップアップが表示される, **Then** AIからの励ましメッセージが一緒に表示される

---

### Edge Cases

- タイマー中にブラウザのタブを切り替えたらどうなる？ → タイマーは継続する（タブ切り替えの検知・停止はスコープ外）
- タスクの締め切りを過ぎたらどうなる？ → 期限切れとして表示されるが、削除はしない
- パスワードを忘れたら？ → パスワードリセット機能はスコープ外。メンターと相談。

## Requirements

### Functional Requirements

- **FR-001**: ユーザーはアカウント名とパスワードでアカウントを新規登録できる
- **FR-002**: ユーザーはアカウント名とパスワードでログイン・ログアウトできる
- **FR-003**: ログインユーザーはタスク名・締め切り日を入力してタスクを登録できる
- **FR-004**: ログインユーザーは自分のタスク一覧を見られる（他のユーザーのタスクは見えない）
- **FR-005**: ユーザーはタスクに対して集中タイマーをスタートできる
- **FR-006**: 集中タイマー画面にはBongoCat風のキャラクターが表示される（複数種類から選択可能）
- **FR-007**: タイマー完了後、その日の達成記録がカレンダーに自動保存される
- **FR-008**: ユーザーはカレンダー画面で日ごとの達成履歴を確認できる
- **FR-009**: ユーザーはタスクに対してAIによるスモールステップ分解を依頼できる
- **FR-010**: タイマー完了後の達成ポップアップにAIからの励ましメッセージが表示される

### Key Entities

- **ユーザー**: アカウント名・パスワード（ハッシュ化）を持つ。自分のタスクのみ管理できる
- **タスク**: タスク名・締め切り日・完了フラグ・登録者（ユーザー）を持つ
- **集中セッション**: どのタスクを・いつ・何分集中したかの記録。カレンダー表示に使う
- **サブタスク**: AIが分解したスモールステップ。親タスクに紐づく

## Success Criteria

### Measurable Outcomes

- **SC-001**: ユーザーが新規登録からタスク登録まで5分以内に完了できる
- **SC-002**: 集中タイマーが正確にカウントダウンされ、完了後3秒以内に達成ポップアップが表示される
- **SC-003**: AIによるスモールステップ提案が15秒以内に表示される
- **SC-004**: カレンダーに過去の達成履歴が正確に表示される

## Assumptions

- ログイン機能はメンターの承認済み。bcryptでパスワードをハッシュ化して実装する
- パスワードリセット・不正ログイン対策などの周辺機能は今回スコープ外
- タスクのデータ（タスク名・締め切り・達成記録）はすべてユーザーが自分で入力する（架空データではなく実ユーザーのデータ）
- キャラクターのイラストは簡易なCSSアニメーションで実装（外部画像サービス不使用）
- タイマーの長さはデフォルト25分（ポモドーロテクニック）。ユーザーが変更できなくてもMVPとして成立する
- ランキング機能はスコープ外
- プッシュ通知・リマインダーはスコープ外
- アイテムショップ・ポイント交換はスコープ外
- 複数人同時利用のリアルタイム機能はスコープ外
